# 🖼️ Canvie

**Your desktop, your canvas.**
**Seu desktop, seu canvas.**

Canvie transforma o desktop do Windows em um espaço visual persistente de pensamento.

Em vez de abrir uma janela para anotar algo, você deixa ideias, imagens, setas e referências direto no próprio desktop — como uma lousa que continua ali.

> Pense visualmente, feche o computador e encontre o mesmo pensamento exatamente onde você deixou.

---

## O que é o Canvie?

O Canvie é uma camada visual persistente sobre o desktop.

Você cria um canvas infinito para organizar pensamentos, projetos, referências e tarefas, sem precisar abrir um aplicativo tradicional de whiteboard.

O canvas não é uma janela. Ele é parte do desktop.

---

## Por quê?

Ferramentas de canvas são poderosas, mas normalmente vivem dentro de uma janela.

O desktop, por outro lado, é o espaço que você já vê e usa todos os dias.

O Canvie usa esse espaço como uma superfície de pensamento persistente: deixar ideias no lugar onde você trabalha.

---

## Como funciona?

### Desktop Mode

O Canvie fica atrás das janelas, como uma lousa que aparece quando o desktop está exposto.

A ideia é simples: seu desktop vira o seu mural.

### Canvas Mode

Com um atalho (`Win + T`), o Canvie vem para frente e vira uma superfície ativa de trabalho.

Aqui você edita, move, desenha e organiza os elementos livremente.

### Overlay Mode

Um canvas transparente sobre outros aplicativos para anotações rápidas.

Rápido de ativar e desativar, focado em desenhar e anotar sem atrapalhar o trabalho principal.

### Lock Mode

Com um atalho (`Ctrl + L`), você congela o canvas.

Os elementos continuam visíveis, mas não podem ser movidos ou editados sem querer.

Lock não é só "somente leitura". É **fixar o pensamento**: você termina uma ideia, trava o canvas e deixa aquela composição no desktop.

---

## Princípios

1. **Desktop first** — O desktop é o produto, não só o lugar onde o produto abre.
2. **Persistent by default** — Tudo que é colocado no canvas permanece salvo.
3. **Fast interaction** — Escrever, arrastar, colar e conectar com o mínimo de fricção.
4. **Quiet UI** — A interface desaparece quando não é necessária.
5. **Friendly** — Amigável, leve e pessoal. Não um SaaS corporativo.

---

## O que dá pra fazer?

Na primeira versão, a ideia é permitir o essencial:

- Navegar pelo canvas com pan e zoom
- Criar e editar blocos de texto
- Desenhar livremente e apagar
- Criar linhas, retângulos e círculos
- Conectar elementos com setas
- Arrastar imagens ou colar direto do clipboard
- Selecionar, mover, redimensionar e apagar elementos
- Desfazer e refazer
- Manter tudo salvo automaticamente, mesmo após reiniciar o Windows

---

## O que o Canvie não é (por enquanto)

Para provar primeiro que o canvas no desktop é útil e agradável, ficam de fora da primeira versão:

- IA, colaboração em tempo real e sincronização em nuvem
- Integrações, calendário, OCR e templates complexos
- Automações, mobile e recursos avançados de produtividade

> Regra: primeiro provar que o canvas no desktop é útil e agradável.

## Atalhos essenciais

| Entrada | Ação |
| --- | --- |
| `Win + T` | Abrir / ativar o Canvas Mode |
| `Ctrl + L` | Alternar o Lock Mode |
| `Ctrl + Z` / `Ctrl + Shift + Z` | Desfazer / refazer |
| `Ctrl + V` | Colar texto ou imagem |
| `Space + arrastar` | Navegar pelo canvas |
| `Scroll` | Zoom do canvas |
| Arrastar arquivo | Adicionar imagem ao canvas |
